# Smart Fleet v3.8.3 — UI รวมฉบับสมบูรณ์

รวมงานที่อนุมัติแล้ว: ประวัติการใช้รถบนมือถือแบบการ์ด ตัวกรองสถานะ หน้ารายละเอียดลำดับเวลา หน้าบัญชีของฉัน ฟอร์มเปลี่ยนรหัสผ่าน และหน้าสำเร็จหลังบันทึก
อิงโค้ด Production v3.8.2 ที่ commit 7f1b677530ef54ad9b081b41cd7b58b2e4d40597 ใน kritsuwan1/smart-fleet

## ฟังก์ชัน

- ประวัติค้นหาและกรองเดือน รถ และสถานะได้ Admin กรองผู้ขับได้
- จำนวนทั้งหมด/รอคืน/คืนแล้ว เปลี่ยนตามตัวกรอง รายการรอคืนมีปุ่มคืนรถโดยตรง
- รายละเอียดแสดงทะเบียน ผู้ขับ โครงการ วันเวลา เลขไมล์ และระยะทาง พร้อมกลับหน้าประวัติโดยคงตัวกรอง
- บัญชีแสดงข้อมูลจริงและสิทธิ์ เปลี่ยนรหัสผ่านได้จากหน้าแยก มีปุ่มแสดง/ซ่อน ตรวจความยาวและยืนยันรหัสผ่าน
- รหัสผ่านใหม่ใช้ 6–128 ตัวอักษรตามระบบเดิม ไม่เพิ่มเงื่อนไขตัวพิมพ์ใหญ่หรืออักขระพิเศษ
- หลังเซิร์ฟเวอร์ยืนยันว่าบันทึกสำเร็จ จะล้างเซสชันตามระบบเดิมและเปิดหน้าสำเร็จ ให้เข้าสู่ระบบใหม่
- บัญชีหลัก admin ยังเปลี่ยน APP_PASSWORD ที่ Cloudflare ส่วน Admin ที่เป็นบัญชีพนักงานเปลี่ยนรหัสตนเองผ่านฟอร์มได้
- รายงาน Excel/PDF และสิทธิ์เดิมคงอยู่ คอมพิวเตอร์ใช้ตารางประวัติ มือถือใช้การ์ด
- ไม่เปลี่ยน schema ฐานข้อมูล ข้อมูลตั้งต้น QR หรือรหัสผ่านใด ๆ โดยการ Deploy

## ตรวจสอบ

Build Demo/Production, TypeScript และชุดทดสอบ API/บัญชี/สิทธิ์/นำเข้า/รายงาน/พื้นที่ข้อมูล/สำรองข้อมูล/สภาพแวดล้อมผ่าน
ทดสอบ UI หน้าแรก ฟอร์มรับคืน ประวัติ ตัวกรอง ลำดับเวลา กรณีข้ามวัน และการรักษาตัวกรอง
ทดสอบเปลี่ยนรหัสผ่าน: ความยาว การยืนยัน payload เซิร์ฟเวอร์ปฏิเสธ เซสชันหมดอายุ เครือข่ายขัดข้อง คำตอบผิดรูปแบบ หน้าสำเร็จ และการยกเลิกเซสชันเดิม
ตรวจเบราว์เซอร์ด้วยข้อมูลจำลองที่ความกว้าง 390px ทั้งหน้าบัญชี เปิดฟอร์ม ปุ่มแสดง/ซ่อนช่องว่าง ยกเลิกกลับ และหน้าสำเร็จจำลอง ไม่เปลี่ยนรหัสผ่านจริงผ่านเบราว์เซอร์

## นำขึ้นผ่าน GitHub Desktop

1. เปิด repository smart-fleet → Fetch origin และ Pull หากมี
2. Repository → Show in Explorer
3. แตก ZIP นี้ แล้วคัดลอกไฟล์ภายในทั้งหมดไปแทนในโฟลเดอร์ repository เดิม เก็บ .git ไว้
4. package.json, src, scripts, tests และ .github ต้องอยู่ระดับแรกของ repository
5. Summary: Update Smart Fleet v3.8.3 complete UI → Commit to main → Push origin
6. GitHub → Actions → Deploy Smart Fleet → Run workflow → main → demo
7. ทดสอบด้วยบัญชีพนักงานและ Admin ใน Demo รวมการรับ–คืนรถ ประวัติ และเปลี่ยนรหัสผ่านของบัญชีทดสอบ
8. เมื่อผ่าน สำรองข้อมูลจริง แล้ว Run workflow อีกครั้งโดยเลือก production

ใช้ GitHub Secrets และ DEMO_DATABASE_ID เดิม ไม่ต้องสร้าง Token ใหม่ ไม่ต้องรัน SQL หรือนำเข้า Excel ใหม่
รอบนี้รวมโค้ดที่เตรียมไว้ทั้งหมดแล้ว แทนชุด history-ui-staged เดิม
