# Smart Fleet v3.8.4 — ปรับขนาดฟอร์มบนมือถือ

อิงโค้ดล่าสุดใน GitHub commit 860de1338826505a7743e36555ca8c787470e789 (v3.8.3) และคง UI ประวัติ/บัญชีรุ่นก่อนครบ
ปรับเฉพาะฟอร์มเริ่มใช้รถและคืนรถที่ความกว้างไม่เกิน 760 CSS px ตามแบบที่อนุมัติ

## สิ่งที่ปรับ

- หัวฟอร์มสูง 56 px และหัวข้อ 20 px
- รูปรถประมาณ 90×60 px ข้อมูลรุ่นและเชื้อเพลิงวางต่อกัน ลดช่องว่าง แต่ไม่ตัดข้อมูลรถ
- ป้ายชื่อช่อง 14 px ข้อความในช่องกรอก 16 px ช่องกรอกสูงอย่างน้อย 46 px
- ระยะระหว่างช่อง 12 px หัวข้อแต่ละส่วนและหมายเหตุใช้พื้นที่กระชับขึ้น
- สรุปตอนรับรถและการ์ดระยะทางลด padding และช่องว่าง
- ปุ่มยกเลิกอยู่ซ้าย ปุ่มยืนยันอยู่ขวาในแถวเดียว ปุ่มยืนยันสูงอย่างน้อย 48 px แถบปุ่มวัดได้ 65 px ในเบราว์เซอร์ทดสอบ (ไม่รวม safe area เพิ่มเติมของเครื่อง)
- เนื้อหายังเลื่อนได้ตามปกติ ไม่บังคับให้ทุกช่องอยู่ในหน้าเดียว ไม่ปิดการซูมหรือกำหนด maximum-scale
- ไม่ปรับหน้าคอมพิวเตอร์ หน้ารายละเอียด ประวัติ บัญชี รายงาน หรือระบบข้อมูล

## ผลทดสอบ

Build Demo/Production, TypeScript และชุดทดสอบเดิมทั้งหมดผ่าน
ตรวจเบราว์เซอร์ด้วยข้อมูลจำลองที่ 390×740 และ 320×680 CSS px
ฟอร์มคืนรถและเริ่มใช้รถไม่ล้นแนวนอน ปุ่มยืนยัน/ยกเลิกสูง 48 px และยกเลิกอยู่ด้านซ้าย
ตัวอักษรช่องกรอกวัดได้ 16 px ป้ายชื่อวัดได้ 14 px หัวฟอร์มวัดได้ 56 px
คืนรถคำนวณระยะทางตัวอย่าง 57 กม. ถูกต้อง และเมื่อเลื่อนถึงท้ายฟอร์ม ช่องหมายเหตุอยู่เหนือแถบปุ่ม อ่านและกรอกได้ครบ
ไม่ได้บันทึกข้อมูลทดสอบลงฐานจริง

ขนาดที่เห็นบนเครื่องจริงยังขึ้นกับขนาดหน้าจอ แถบเบราว์เซอร์ การตั้งค่าขนาดข้อความ และ safe area ของเครื่อง

## อัปเดตผ่าน GitHub Desktop

1. เปิด smart-fleet → Fetch origin / Pull origin หากมี
2. Repository → Show in Explorer
3. แตก ZIP นี้ คัดลอกไฟล์ภายในทั้งหมดไปแทนในโฟลเดอร์ repository เดิม เก็บ .git ไว้
4. Summary: Adjust Smart Fleet v3.8.4 mobile form spacing
5. Commit to main → Push origin
6. GitHub Actions → Deploy Smart Fleet → Run workflow → main → demo
7. ตรวจ v3.8.4 บนมือถือ โดยรีเฟรชหน้าและทดลองรับ–คืนรถใน Demo
8. เมื่อผ่าน สำรองข้อมูลจริง แล้ว Run workflow เลือก production

ใช้ Secrets และ DEMO_DATABASE_ID เดิม ไม่ต้องรัน SQL หรือนำเข้าข้อมูลใหม่
ไฟล์ชุดนี้พร้อมสำหรับอัปเดต แต่การจัดทำไฟล์ไม่ใช่หลักฐานว่า Deploy บน Cloudflare แล้ว
