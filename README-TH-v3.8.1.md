# Smart Fleet v3.8.1 — UI แบบที่ 1 ที่อนุมัติ

อิงฟังก์ชัน v3.8.0 ตามคำขอ ปรับดีไซน์เมนูสีเขียวเข้ม การ์ดรถและข้อมูลรถให้เด่น ปุ่มคืนรถสีฟ้า และการ์ดรอคืนรถพื้นเหลืองอ่อนขอบส้ม บนคอมพิวเตอร์อยู่ข้างรถ บนมือถืออยู่ใต้การ์ดรถ

ไม่เพิ่มหรือตัดฟังก์ชัน v3.8.0 และไม่เปลี่ยนข้อมูลเริ่มต้น/โครงสร้างฐานข้อมูล ข้อมูลเลขไมล์ ผู้ขับ เวลา และสถานะยังอ่านจากฐานของแต่ละฝั่ง ไม่มีตัวเลขจำลองที่ใช้ในการออกแบบใส่ลงข้อมูลจริง

## ไฟล์

- Demo/smart-fleet-demo-v3.8.1.js ใช้กับ Worker smart-fleet-demo และ binding DEMO_DB
- Production/smart-fleet-production-v3.8.1.js ใช้กับ Worker smart-fleet และ binding DB
- source/ มีโค้ดและชุดทดสอบ

## ขั้นตอน Deploy ด้วย Dashboard

1. ดาวน์โหลด SQL สำรองของแต่ละฝั่งและเก็บโค้ดเดิม
2. เปิด Worker smart-fleet-demo → Edit code วางโค้ดจากไฟล์ Demo ทั้งหมด → Deploy คง DEMO_DB → smart-fleet-demo และ APP_PASSWORD ของ Demo
3. เปิด Visit ตรวจ v3.8.1 แถบ DEMO เมนูเขียวเข้ม และการ์ดรอคืนรถสีเหลือง คลิกดูรายละเอียดและเปิดฟอร์มคืนรถ ตรวจทะเบียน/เลขไมล์
4. เปิด Worker smart-fleet → Edit code วางไฟล์ Production ทั้งหมด → Deploy คง DB → smart-fleet-production และ APP_PASSWORD เดิม
5. เปิด Visit ตรวจ v3.8.1 จำนวนข้อมูลเดิม (ซ่อนแถบ PRODUCTION แล้ว)

ไม่ต้องรัน SQL เพิ่มหรือสร้างฐานใหม่ ไม่ต้องนำเข้า Excel ใหม่ URL และ QR เดิมยังใช้ได้ ไฟล์สองฝั่งเปลี่ยนแทนกันไม่ได้เพราะมี guard ฝั่งและฐานข้อมูล

ชุดนี้เป็นสาย v3.8 หากได้เริ่มใช้ฟังก์ชันหรือแนบรูปใน v3.9 แล้ว ให้ปรับ UI บนสาย v3.9 แทนการลดรุ่นมาใช้ชุดนี้

## ผลตรวจสอบ

Build และ TypeScript ผ่าน ชุดทดสอบ worker/import/accounts/roles/reports/system status/backups/environments ผ่าน ตรวจ UI ด้วยฐานข้อมูลจำลองบนคอมพิวเตอร์และมือถือ 390px เปิดดูรายละเอียดจากการ์ดรอคืนรถและเปิดฟอร์มคืนรถถูกต้อง แถบพื้นที่อยู่ท้ายภาพรวม ไม่มีปุ่มเพิ่มรถ/นำเข้า/ส่งออก Excel บนภาพรวม

## พัฒนา/Deploy ผ่าน CLI

ใช้ Node.js 24 ใน source/:

```bash
npm ci
npm run build
npm run typecheck
npm test
```

สำหรับผู้ดูแลที่เข้าสู่ระบบ Wrangler แล้ว ใช้ wrangler.demo.jsonc หรือ wrangler.production.jsonc ให้ตรงฝั่ง ต้องใส่ ID ฐาน Demo จริงในไฟล์ demo ก่อนใช้ CLI ส่วน Dashboard ใช้ binding ที่ตั้งไว้เดิมได้ ไม่ต้องใส่ ID ในโค้ด Worker

การตรวจสิทธิ์ Deploy ในรอบนี้พบว่า Wrangler ยังไม่ได้เข้าสู่ระบบ Cloudflare จึงต้องเชื่อมบัญชีก่อน Deploy จริง ไฟล์พร้อมใช้ไม่ใช่หลักฐานว่าเผยแพร่แล้ว

## ปรับข้อความ Production

ซ่อนแถบ “PRODUCTION — ระบบใช้งานจริง” และ “ข้อมูลใช้งานจริงของบริษัท” ทั้งหน้าล็อกอิน สมัครสมาชิก และหน้าภายในแอป ฝั่ง Demo ยังแสดงแถบทดสอบตามเดิม
